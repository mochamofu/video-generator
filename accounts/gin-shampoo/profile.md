# アカウント②: GIN. オーガニックシャンプー(自社製品)

## ポジショニング
「売り込み」に見せない製品アカウント。**髪と頭皮の悩み解決コンテンツ**が主役で、
GIN.は解決策として自然に登場する構成(9割お役立ち:1割製品)。

- ターゲット: 髪・頭皮ケアに関心のある層(性別・年代は実際の顧客層に合わせて調整)
- 差別化: 実写の製品・使用シーン・テクスチャ(泡、とろみ)を見せられるのは公式だけ
- テーマ: `forest`(自然・オーガニック系)

## ネタの柱
1. 悩み解決系(フック): 「シャンプーの正しい順番」「頭皮の乾燥対策」「夜まで香りを残す方法」
2. 成分解説系: オーガニック成分の役割をひとつずつ(「◯◯エキスは何のため?」)
3. 製品の裏側系: 製造・香りの調合・パッケージのこだわり(公式ならではの信頼構築)
4. 使い方系: 実写でGIN.を使う正しい洗い方・すすぎ方・量
5. UGC/レビュー系: お客様の声の紹介(許諾を得たもの)

## 実写素材の使い方(scenes[].media)
- 製品ボトル、泡、テクスチャ、洗面所シーンの写真/動画を `assets/media/gin/` に置き、
  台本の各シーンに `"media": "assets/media/gin/xxx.jpg"` で埋め込む
- キャラ(ナレーター)は残してもいいが、製品系は media 主役+キャラ無しも可
  (台本に `"character_width": 0` で非表示)

## 法規制 — 薬機法(必読)
- シャンプーは化粧品。**効能は化粧品の効能56項目の範囲内**で表現する
  - OK: 「フケ、カユミを防ぐ」「毛髪にはり、こしを与える」「頭皮、毛髪をすこやかに保つ」「香りを与える」
  - NG: 「育毛」「発毛」「薄毛が治る」「アトピーに効く」など医薬品的効能
- ビフォーアフターで効果を保証する見せ方はNG寄り。使用感・感想として表現
- 「オーガニック」訴求は根拠(認証・成分比率)と整合させる
