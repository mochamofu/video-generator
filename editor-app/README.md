# shortgen Editor

Premiere Proのようなマルチトラックタイムラインで、動画・画像・音声・テキストを
ドラッグ&ドロップで組み立てて縦動画/横動画を書き出せる、ローカル完結の動画編集ツール。

既存の `shortgen`(台本JSON自動生成パイプライン)とは独立して使えます。

## 特徴

- **マルチトラックタイムライン**: 映像/画像トラック・テキストトラック・音声トラックを好きな数だけ追加
- **ドラッグ&ドロップ**: メディアビンからタイムラインへドラッグして配置。クリップの移動・トリム(端をドラッグ)・分割(S)・削除(Delete)
- **縦動画/横動画切替**: 9:16(ショート動画)・16:9(YouTube等)・1:1・4:5 をワンクリックで切替
- **WYSIWYGプレビュー**: プレビューと書き出し結果が完全に一致(同じRemotionコンポジションを使用)
- **オンキャンバス位置調整**: プレビュー上でテキストや映像の配置をドラッグして微調整
- **プロジェクト保存/読込**: ローカルにJSON保存。いつでも再開可能
- **書き出し**: ボタン1つでmp4レンダリング→ダウンロード

## セットアップ・起動(初回もこれだけ)

```bash
cd editor-app
./start.sh
```

初回は依存パッケージのインストールが自動で走ります(数分)。起動後、ブラウザで
**http://localhost:5173** を開いてください。

必要環境: Node.js 18+、ffmpeg/ffprobe(PATHに通っていること)。

## 使い方

1. 左の「メディアビン」に動画・画像・音声ファイルをドラッグ or クリックして追加
2. タイムラインの映像/音声トラックへメディアをドラッグ(またはダブルクリックで再生ヘッド位置に追加)
3. 「＋テキストを追加」でテロップを追加、インスペクタで文言・フォント・色・位置を調整
   (プレビュー画面上でも直接ドラッグして位置調整可)
4. クリップの端をドラッグでトリム、選択して「S」キーで分割、「Delete」で削除
5. 上部の比率セレクタで縦動画/横動画を切替
6. 「💾 保存」でプロジェクトを保存、「🎬 書き出し」でmp4を生成してダウンロード

## アーキテクチャ

```
editor-app/
  server/   … Express API (メディア管理・プロジェクト保存・Remotionレンダリング起動)
  client/   … React + Zustand製のタイムラインUI (Vite)
../remotion/src/timeline/TimelineComposition.tsx
          … プレビュー(@remotion/player)と書き出し(remotion render)の両方で使う
            共通の合成コンポーネント。プレビューと書き出しが常に一致する設計
```

プロジェクトのデータ形式は [`SCHEMA.md`](./SCHEMA.md) を参照。

## 既知の制限(v1)

- トランジション効果・カラーグレーディング・キーフレームアニメーションは未対応
- 同一トラック内でのクリップ重なりは防止されない(重ねて配置すると同時に再生される)
- Undo/Redoは未実装
- 主に PC のマウス操作を想定(タッチ操作の精密なトリムは未検証)

より簡易な「台本JSON→ショート動画」の自動生成フローは `../shortgen`
(`python3 -m shortgen edit` のCapCut風エディタ含む)を参照してください。
このEditorはより自由度の高い手動編集向けの別ツールです。
