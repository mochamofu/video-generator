# ショート動画 台本作成ルール

このプロンプトは、Claude(Claude Code本体 or `shortgen new` 経由のAPI)が
台本JSONを書くときの共通ルール。

## フォーマット

```json
{
  "title": "動画タイトル(15文字以内、\\nで改行可)",
  "theme": "midnight | sunset | forest | paper | crimson",
  "hashtags": ["#タグ1", "#タグ2"],
  "scenes": [
    {
      "text": "画面テロップ(25文字以内、\\nで改行可)",
      "narration": "読み上げ原稿(自然な話し言葉)",
      "min_duration": 2.5
    }
  ]
}
```

- `narration` 省略時は `text` を読み上げる
- `min_duration` 省略時は 2.2秒(音声がそれより長ければ音声に合わせる)
- `bgm` に音声ファイルパスを入れると音量22%でループミックスされる

## 構成のルール

1. **1シーン目 = フック**: 疑問形・意外な事実・具体的な数字で手を止めさせる
2. シーンは **5〜8個**、ナレーション合計 **250文字程度**(=動画45秒以内)
3. テロップは短く強く。ナレーションは補足を含む話し言葉
4. 最後のシーンは **行動喚起**(保存・フォロー・コメント誘導)or 強い締め
5. 誇張・虚偽は禁止。医療・投資などは断定を避ける
6. ハッシュタグは日本語で4〜6個、ビッグタグ+ニッチタグを混ぜる
