# 生徒個別管理表（刷新版） (student-tracker)

SnsClubの「初投稿までのタスク管理表」を刷新した、**講師用の生徒一括管理システム**です。従来の「生徒ごとにシートをコピーして配る」運用の弱点（全体像が見えない・期日を手入力・遅れに気づけない）を解消します。

## 新しくできること

| 従来 | 刷新版 |
|---|---|
| 生徒ごとに別ファイル | 1つのスプレッドシートに全生徒を集約 |
| 進捗は各ファイルを開いて確認 | 📊 ダッシュボードで全生徒の進捗率を一覧 |
| 目標期日を手入力 | 開始日を入れるだけで全25ステップの期日を自動計算 |
| 遅れに気づけない | 期日超過タスクを自動で⚠️表示＋赤字ハイライト、朝のアラートメール（任意） |
| 完了日を手入力 | チェックを付けると完了日を自動記録 |

## セットアップ（5分）

専用のスプレッドシートを作成済みです:
**[生徒個別管理表（刷新版）](https://docs.google.com/spreadsheets/d/10q8GUQa0BgjKjOnwwqLy0Yb2dCES2DrmmAaULLe2oXc/edit)**

1. 上のスプレッドシートを開き、**拡張機能 > Apps Script**
2. `src/` の3ファイル（`main.gs` `roadmap.gs`、必要なら`appsscript.json`）を貼り付けて保存
3. スプレッドシートをリロード → メニューに「📋 生徒管理」が出ます
4. 「⚙️ 初期セットアップ」を実行（初回のみ。権限承認が出ます）
5. 「👤 生徒を追加」で名前と開始日を入力 → 個別シートが自動生成されます

## 日々の使い方

- **生徒の課題が終わったら**: 個別シート（👤 名前）の「完了」列にチェック → 完了日が自動記録
- **全体を見たいとき**: 📊 ダッシュボードを開いて「🔄 ダッシュボードを更新」→ 遅れている生徒が上に並びます
- **朝のアラートメール（任意)**: Apps Scriptで `setupDailyTrigger` を一度実行し、スクリプトプロパティ `ALERT_EMAIL` に通知先アドレスを設定すると、毎朝7時台に期日超過の生徒一覧が届きます

## カリキュラムの変更

`roadmap.gs` の `ROADMAP` を編集してください（プログラム/ステップ/課題内容/教材リンク/目安日数）。変更後に追加した生徒から新しいカリキュラムが反映されます。

## 補足

- 生徒シートの行を直接編集しても壊れません（集計はプログラム名・完了チェック・期日列だけを見ています）
- 卒業した生徒はシートを削除すればダッシュボードから消えます（更新を実行）
