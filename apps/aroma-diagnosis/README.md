# 香り診断アプリ (aroma-diagnosis)

「今のあなたにピッタリの香りは？」— 7つの質問に直感で答えると、今の心と体の状態に合わせた**5タイプのアロマブレンド**を提案するWebアプリです。

COCORO Labの脳波アロマ事業（セレニアアロマ）のInstagram導線（プロフィールリンク → 香り診断 → オーダーメイドアロマ）用に設計しています。

## 構成

- **フロントエンド**: ビルド不要の静的サイト（`index.html` / `style.css` / `app.js`）
- **バックエンド**: Supabaseプロジェクト `aroma-shindan`（診断結果の匿名保存・集計用）
  - テーブル `diagnosis_results` は作成・適用済み（`supabase/migrations/` 参照）
  - フロントには公開用キー(publishable key)のみを使用。RLSにより匿名ユーザーは**登録のみ可能・閲覧不可**

## 診断ロジック

7問の回答が5タイプ（やすらぎ/おやすみ/クリア/リフレッシュ/ひだまり）へ加点され、最高得点のブレンドを提案します。質問・ブレンド内容は `app.js` の `QUESTIONS` / `RESULTS` を編集するだけで変更できます。

| タイプ | ブレンド | 精油 |
|---|---|---|
| relax | やすらぎブレンド | ラベンダー × ベルガモット |
| sleep | おやすみブレンド | ラベンダー × スイートオレンジ × カモミール |
| focus | クリアブレンド | ローズマリー × レモン × ペパーミント |
| refresh | リフレッシュブレンド | グレープフルーツ × ユーカリ |
| uplift | ひだまりブレンド | ベルガモット × イランイラン × スイートオレンジ |

## 公開方法（どれか1つでOK）

1. **GitHub Pages**: リポジトリのSettings > Pagesで `apps/aroma-diagnosis` を公開
2. **Netlify / Vercel**: このフォルダをドラッグ&ドロップでデプロイ
3. ローカル確認: フォルダ内で `python3 -m http.server` → http://localhost:8000

公開後、InstagramのプロフィールリンクにURLを設定してください。

## 公開前にやること

- `app.js` の `ORDER_URL` をオーダー受付ページ（LINE公式・BASEなど）のURLに差し替える
- 診断結果の件数を確認したいときは、SupabaseダッシュボードのTable Editorで `diagnosis_results` を参照（タイプ別集計は `diagnosis_stats` ビュー）

## 注意事項

- 結果画面・スタート画面に「医療行為ではありません」の免責を明記済み（薬機法・医師法対応）
- Supabaseの無料プランはプロジェクトが1週間アクセスなしで自動休止します。休止した場合はダッシュボードからRestoreしてください（データは消えません）
