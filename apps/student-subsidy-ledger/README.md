# 生徒個別管理表（補助金・管理会計） (student-subsidy-ledger)

生徒ごとの**毎月の補助金がいくら必要になるか**を自動計算し、管理会計を簡単にするスプレッドシートです。

**作成済みのシート（サンプルデータ入り・数式動作確認済み）:**
[生徒個別管理表（補助金・管理会計）](https://docs.google.com/spreadsheets/d/1D9ajQLiYOJ81Ij9kxizgTYhy47LiXdzsYJFQlOBnRh4/edit)

## 使い方

生徒を1行追加して、以下を入れるだけです。

| 列 | 入力内容 |
|---|---|
| 生徒名 / コース | 任意 |
| 在籍状態 | `在籍` / `休会` / `卒業`（在籍のみ計算対象） |
| 月額受講料 | 円 |
| 月額補助金 | その生徒に毎月必要な補助金額（円） |
| 補助開始月 / 補助終了月 | `2026/07/01` のように月初日付で入力 |

月列（2026/07〜2027/06）には数式が入っており、**補助期間内かつ在籍中の月だけ**補助金額が自動で立ちます。新しい行を追加したら、既存行の月列セルを下へコピーしてください。

下部の集計行で毎月分かること:

- **📊 必要補助金 合計** — その月に用意すべき補助金の総額
- **💰 受講料収入 合計** — 在籍生徒の受講料合計
- **👛 生徒自己負担 合計** — 受講料と補助金の差額

## 月列を増やしたいとき

S列の右にヘッダー（例 `2027/07/01`）を足し、既存の月列を右へコピーするだけです。集計行も同様に右へコピーしてください。

## 検証済みの動作

サンプルデータで以下を確認済みです。

- 補助開始月より前の月は0円（例: 8月開始の生徒は7月が0円）
- 補助終了月の翌月から0円
- 休会中の生徒は全月0円
- 補助金なし（0円）の生徒は集計に影響しない

`template.csv` は同じ内容のテンプレートです。Googleスプレッドシートで「ファイル > インポート」すると数式ごと再現されます。
